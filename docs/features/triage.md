# Triage (§16.3, Full mode)

More → **Triage**: review Planned items (or a list or saved view) one card at a time.

Keys: **K** keep, **U** Up Next, **S** snooze 30 days, **H** on hold, **D** drop (confirmation only when the
item has progress), **N** skip, **Z** undo last (unlimited in the session), **O** open details. Each action
and progress (“12 of 80 reviewed”) is announced. At the end: a summary and **Undo all**. The position is
remembered for the session. Status changes are logged in Recent changes.
