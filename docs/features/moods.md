# Moods

Small labels such as Cozy, Short on time or Mind-bending. Nine built-in moods are created by the migration, and you can add up to 60 in total.

- **Item page → Moods:** toggle buttons (each with `aria-pressed` and a ✓/+ marker, so the state isn't shown by color alone). Up to 12 per item.
- **Library bulk:** add or remove one mood on many items in a single transaction (`moods:bulk`).
- **Use:** What fits? (Pile page), the Mood filter in Pick for Me, and recommendations ("a mood you often finish").
- **Settings → Features → Moods:** create, hide or delete moods. Built-in moods can be hidden or renamed, but not deleted.
