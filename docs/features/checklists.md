# Checklists (§14.9, Full mode)

Each item can have one ordered checklist (“Finish the DLC”, “Platinum trophy”): add, edit, reorder with
buttons, check/uncheck, delete; progress “3 of 5” on the item, cards and the Continue row.

Checklists are separate from progress and **never change the status**; completing one only suggests
marking the item Completed. Templates can pre-fill checklists. Data: `checklists`, `checklist_items`
(deleted with the item). Exported in JSON and full backups.
