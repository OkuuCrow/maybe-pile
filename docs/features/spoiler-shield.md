# Spoiler Shield

- **Per item:** Preferences → Spoiler Shield (Use app default / Always / Never). **App default:** Settings → Features → Spoiler Shield, which is off by default and never applies to completed items.
- **When it's active,** episode titles after your next unwatched episode are replaced with the text "Title hidden (Spoiler Shield)". A status notice offers **Reveal everything on this page**.
- **"My notes contain spoilers"** hides the notes behind a **Reveal notes** button.
- **Accessibility:** hidden content is replaced by plain text and a labelled button, never just blurred or colored. Revealing lasts only for the current view.
