# Completion heatmap

Stats → Charts shows a calendar grid of completions for the selected year (or the latest year). It counts every completed run, so rewatches and replays count.

**Accessibility:**

- Intensity is shown by color **and** by 1, 2 or 3 dots.
- Each day with completions is focusable, and its label reads like "2025-03-10: 2 completions — titles…".
- **Show as table** lists every day with its count and titles.
- In forced-colors mode, cells keep visible borders.
