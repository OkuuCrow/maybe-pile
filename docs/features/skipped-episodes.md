# Skipped episodes (§16.8)

TV/anime episodes can be **Skipped** (fillers, recaps, specials): per-episode *Skip/Un-skip* and *Mark
unwatched as skipped* per season.

Skipped episodes count toward “caught up” and completion, are reported separately (“22 watched · 3 skipped ·
25 total”), are passed over by “next episode” (and the “next: S1E12” reminder text), and **never** count as
watched episodes in stats/goals or as watch time. Data: `episodes.skipped`, `run_episode_states.skipped`.
