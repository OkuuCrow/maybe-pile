# Bulk edit (§16.4, Full mode)

Library → select → **Edit N selected…**: set status, rating (or clear), tags (add/remove/replace), list
membership, platform (games). A live preview shows how many items change and **per-item exceptions** (for
example a platform for non-games, items in Recently deleted). Domain rules are never bypassed: status
changes go through the normal status logic. One transaction; one **Undo** for the whole edit (toast and
Recent changes). Basic bulk actions (status, tags, delete) remain in Simple Mode.
